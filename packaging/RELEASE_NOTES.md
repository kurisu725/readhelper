支持文献导入、阅读、带出处的 AI 分析与本地笔记。

- Windows 扫描 PDF 支持本地 RapidOCR 文字识别，安装包内置 CPU 推理运行环境和中英文模型，无需额外下载。支持识别本页、识别全书、停止和断点继续，结果可用于搜索、笔记与 AI 分析。
- 新增默认关闭的“研究方向与导图”插件，可在“插件与更新”中启用。支持按主题检索 OpenAlex、Semantic Scholar、Crossref 与可选 arXiv，并生成可折叠的研究问题和方向导图。
- 研究梳理保留论文来源和摘要证据，区分论文报告的问题与模型推断的研究机会，支持取消、重试、历史记录以及 Markdown / JSON 导出。分析基于检索到的摘要，需配置 AI 服务。
- 建筑史研究作为可选插件，包含史料证据卡、建筑沿革时间轴、学术观点与争议对照。
- 新安装默认通用研读；旧版已有建筑史记录自动保留并启用对应插件。
- Windows x64 安装包内置 Python，通过默认浏览器显示本地工作台。
- macOS 安装包内置运行环境，使用原生窗口；支持 Apple Silicon 和 Intel（macOS 14+）。
- “插件与更新”默认连接 `kurisu725/readhelper`，支持公开仓库或使用本机令牌访问私有仓库的正式 Release，下载、校验并打开安装包。资料和配置独立保存。

安装包暂未使用开发者证书签名 / Apple 公证。macOS 包有本地临时签名。
更新前请退出旧程序；Mac 将应用拖入“应用程序”，Windows 运行安装程序。
Windows 使用 RapidOCR，macOS 使用系统 Vision OCR；识别结果保存到本地资料库，原 PDF 保持不变。
